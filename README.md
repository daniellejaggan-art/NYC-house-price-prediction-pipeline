NYC House Price Prediction PipelineProject OverviewThis project develops an end-to-end data pipeline for preparing and analyzing NYC property sales data and building a machine learning model to predict property sale prices.The project uses PostgreSQL for data storage and SQL-based data preparation, followed by Python for data inspection, preprocessing, model development, and evaluation.The primary machine learning model is a Random Forest Regressor, compared against a Linear Regression baseline.Project Objectives* Prepare and organize NYC property sales data.* Identify and address data quality issues.* Create a model-ready dataset using SQL.* Explore relationships between property characteristics and sale prices.* Train and evaluate regression models.* Generate property price predictions.Technologies Used* PostgreSQL Ð Data storage and SQL transformations* Python Ð Data analysis and model development* Pandas & NumPy Ð Data manipulation* Scikit-learn Ð Preprocessing, model training, and evaluation* Jupyter Notebook Ð Exploratory analysis and model development* Git & GitHub Ð Version control and project documentationProject Workflow1. Data Preparation Ð PostgreSQLThe original dataset contained 80,476 property sale records.SQL was used to inspect the dataset, investigate missing values and unusual transactions, and prepare the data for modeling.Data quality investigations included:* Zero-dollar sale transactions* Duplicate property transactions* Missing property characteristics* Unusual sale prices and potential outliersA model-ready table was created containing 23,306 records and seven columns, with no missing values.2. Data Analysis and Preprocessing Ð PythonThe prepared dataset was loaded into a Jupyter Notebook for further inspection and preprocessing.The model used six input features:* Borough* Building class at time of sale* Gross square footage* Total units* Year built* Land square footageThe target variable was sale_price.Categorical and numerical features were handled using Scikit-learn preprocessing pipelines.3. Model DevelopmentTwo regression models were evaluated:* Linear Regression Ð baseline model* Random Forest Regression Ð primary modelRandom Forest was explored to capture more complex relationships between property characteristics and sale prices.4. Model EvaluationModels were evaluated using:* Mean Absolute Error (MAE)* Root Mean Squared Error (RMSE)* R-squared (R?)Additional analysis explored the effect of unusually low sale prices and extreme values on model performance.Project StructureNyc_dataset/???? models/?   ??? nyc_house_price_model.joblib???? notebooks/?   ???
